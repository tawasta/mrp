=================================
Hazard Residual Risk Default Name
=================================

* The name of a new residual risk evaluation defaults to the name of the hazard.

Configuration
=============
\-

Usage
=====
* Open a hazard and go to the Residual Risk Evaluations tab. Add a line: the
  name is filled with the name of the hazard. The name can be changed.
