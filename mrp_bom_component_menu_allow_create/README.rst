===================================================
MRP BOM Component Menu – Allow Create functionality
===================================================

::

    Bypass the restriction that disabled creating BoM line records
    in MRP Component Menu. Only use this module to help users to
    import BoMs by having bom_id -field set on each excel line. So
    if a customer has thousands of lines, each line needs to have
    a bom_id -info set, which is a wanted behaviour.


Configuration
=============
::

    There is no need to configure anything

Usage
=====
::

    Install the module and go to MRP Component Menu to try importing Boms

Known issues / Roadmap
======================
::

    Be wary to allow this behaviour and preferably only use the module
    in the installations with few users.
