========================================
MRP – Module to log MRP related problems
========================================
::

    Logging information related to MRP actions. Feel free to
    expand and modify this module to diagnose possible problems.

Configuration
=============
::

    None needed

Usage
=====
::

    Go to Apps and install the module

Known issues / Roadmap
======================
::

    Note how function inherits are done. It is done directly
    modifying the source function, so different modules that
    inherit same functions are not affected by this module.
