======================================================================
Show confirm message before producing a product in Manufacturing order
======================================================================

Sometimes users may press "Produce All" button too quickly. This module
adds a confirmation message, an extra step, to first ask a user if he/she
really wants to product all products.

Configuration
=============
The module works without configuring anything.

Usage
=====
Go to a manufacturing order and press Produce/Produce All button. Then
a confirmation message should be shown to a user.

Known issues / Roadmap
======================
There should be no issues with the module, because it only adds an extra step
to the production chain.
