=================================================
MRP: Show Operations' Sequence Field in Form View
=================================================

* Shows the sequence that was visible in 14.0 but
  has since then been hidden in core.

Configuration
=============
* None needed

Usage
=====
* Open Manufacturing -> Configuration -> Operations Form
  to see the field
