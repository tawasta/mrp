===================================================================
Quality Control OCA: Specific Default Value for Freetext Questions
===================================================================

* Adds a "Use specific pre-fill value" toggle and a "Default value"
  field to freetext test questions.
* Lets you define, per question, the text that should be used to
  pre-fill the answer when the test's "Pre-fill with correct values"
  option is enabled, instead of always leaving it empty.

Configuration
=============
* None needed

Usage
=====
* When defining a freetext test question, optionally enable "Use
  specific pre-fill value" and set the "Default value" that appears.
* If "Use specific pre-fill value" is left disabled, pre-fill leaves
  the answer empty, as before this module was installed.
