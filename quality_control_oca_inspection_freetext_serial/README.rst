================================================
Quality Control OCA: Inspection Freetext Serial
================================================

* Adds a freetext "Serial Number / Identifier" field to inspections.
* Lets you look up inspections that pertain to a certain serial
  number or other identifier.
* Not connected to Odoo's own serial number / lot tracking - it is a
  plain freetext field.

Configuration
=============
* None needed

Usage
=====
* Just fill in the "Serial Number / Identifier" field on an inspection,
  and use it to search filter inspections
