=========================================================
Quality Control OCA: Freetext Values for Inspection Lines
=========================================================

* New answer type in addition to qualitative and quantitative values
* Intended for situations where qualitative values' dropdown is not 
  feasible, and you need to be able to type in freeform text to
  describe what was checked during the quality control.
* All answers are considered as accepted, so there is no validation
  applied to the text inputs.

Configuration
=============
* None needed

Usage
=====
* When defining a test, select the new answer type for a test question
* When answering the test, enter a freetext answer value
